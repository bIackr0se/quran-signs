# Signs Within Yourselves

The human life cycle in the Qur'an, from dust to resurrection, in fifteen passages.

**Watch:** https://biackr0se.github.io/quran-signs/

Each passage plays with the recitation of Mishary Alafasy. Painted scenes and live light follow each recited word, and each stage in the womb sits beside what embryology found centuries later. It also plays in silence.

The film opens in Arabic, and one tap switches the explanations and controls to French or English. The ayat are always in Arabic, with a transliteration and a French or English gloss of each phrase as it is recited.

It is one HTML file with a canvas engine and no framework. Headphones help.

## Sources

- Ayah text: Uthmani script and the Sahih International translation, from api.alquran.cloud. No ayah text is typed by hand.
- Recitation audio and word timings: the quran.com API (verses.quran.com).
- Embryology notes: standard embryology references, with the classical tafsir named where a note cites it.

## Controls

Space pauses, the arrow keys move between passages, F is fullscreen.
